# Akarin（紲星あかり）パートナー

これは紲星あかりの非公式ファンメイドの人格（Persona）です。権利者とは無関係であり、公式・公認のものではありません。

- 公式の画像や音声は含みません。
- `identity/official.md` には、公式情報が述べている内容だけを書きます。出典は https://vocalomakets.com/kizuna-akari と、ガイドライン https://vocalomakets.com/guidelines です。
- 二次設定は `identity/fanon.md` に分けて書き、公式設定と矛盾させません。
- Yunomi 固有の振る舞い原則は `identity/yunomi.md` に書きます。

`profile.yaml` または `identity/` を変えたら `pnpm --filter @yunomi/partner-akarin gen` で `src/generated/profile.ts` を再生成します。

`profile.yaml` の各項目の意味は `partners/yukarin/README.md` と同じです。`voice` はまだ持たないので、Akarin の返事は声にしません。
